# 🛠️ راهنمای توسعه و راه‌اندازی (Development Guide)

این راهنما دستورالعمل‌های گام‌به‌گام برای نصب، راه‌اندازی، توسعه و بیلد این سامانه ERP را ارائه می‌دهد.

---

## ۱. پیش‌نیازها (Prerequisites)
- Node.js (نسخه ۱۸ یا بالاتر)
- پکیج منیجر (npm, pnpm یا bun)

---

## ۲. مراحل نصب و راه‌اندازی (Installation Steps)

1. **کلون کردن پروژه یا استقرار در محیط**:
   مخزن پروژه را در محیط کاری خود باز کنید.

2. **نصب وابستگی‌ها (Dependencies)**:
   ```bash
   npm install
   ```

3. **تنظیم متغیرهای محیطی**:
   فایل `.env.example` را بررسی کرده و در صورت نیاز فایل `.env` را ایجاد کنید:
   ```env
   VITE_APP_TITLE=Enterprise ERP System
   ```

4. **اجرای سرور توسعه (Development Server)**:
   ```bash
   npm run dev
   ```
   برنامه روی پورت پیش‌فرض `3000` و آدرس `http://localhost:3000` اجرا خواهد شد.

---

## ۳. فرآیند بیلد و تولید نسخه نهایی (Build Process)
برای کامپایل و ساخت نسخه پروداکشن:
```bash
npm run build
```
فایل‌های خروجی در پوشه `dist/` قرار می‌گیرند و آماده استقرار روی سرورهای وب (مانند Nginx یا Cloud Run) هستند.

---

## ۴. بررسی کیفیت کد و لینت (Linting & Type Checking)
برای بررسی خطاهای تایپ‌اسکریپت و صحت ساختار کد:
```bash
npm run lint
```
این دستور از `tsc --noEmit` استفاده می‌کند تا اطمینان حاصل شود که هیچ خطای تایپی یا مفقودی در پروژه وجود ندارد.
